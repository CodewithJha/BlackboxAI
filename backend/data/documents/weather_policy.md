# Weather Alert & Response Policy

This document outlines the standard responses for severe weather conditions within BlackBox AI client regions.

## Temperature Guidelines
When temperatures exceed 35°C or drop below -5°C, agent responses must include a safety advisory warning users to stay indoors.
For moderate climates (10°C to 28°C), standard response rules apply.

## Rainfall Protocols
If rainfall probability is above 60%, recommend users to carry an umbrella.
If weather reports show storms or typhoons, alert the operations manager immediately.
Weather records are fetched from Open-Meteo current forecast endpoints.
